> コードネーム: **Kiso**（木曽ヒノキの森。伊勢神宮の建て替えにも使われる建材。「基礎」と同じ音で、最初の版＝アプリの土台をつくる版、という意味）

> 親Issue: 未作成
> 仕様: [product-plan.md](../product-plan.md)（仕様書 v0.2.4）

---

## 1. 目的

| # | 目的 | 測り方（案） |
|---|---|---|
| G1 | **毎月の合計収支が見える**：物件ごと・口座ごとに、いつ・いくら入って出ていくかを「予定」として示す | 物件登録を終えた人の割合、入出金タブの表示回数 |
| G2 | **引き落とし前に気づける**：引き落とし前日の通知で、口座の残高不足を防ぐ | 通知を許可した人の割合、通知のタップ率 |
| G3 | **スタンダードへの入口をつくる**：6件目の物件・ローン詳細・分析タブから、有料プランに案内する | フリー → スタンダードの転換率 |

## 2. 範囲（1.0.0 に入れるもの）

仕様書 v0.2.4 のフリー／スタンダードの機能を対象にする。プレミア（クラウド同期・統合ダッシュボード・FP共有）は入れない。

| 区分 | 内容 |
|---|---|
| 画面 | S-01 ホーム、入出金、イベント、S-19 分析（スタンダード）、S-04 設定、S-05 物件詳細、S-06 収支記録、S-07 物件登録ウィザード、S-14〜S-18 編集画面 |
| データ | 端末内 SQLite（[frontend-schema.md](../../030.database/frontend-schema.md)） |
| 通知 | 引き落とし前日、契約満了の3ヶ月前、総会シーズン、イベント期日（[product-plan.md](../product-plan.md) / [handoff](../handoff-2026-11-20.md) §8） |
| 認証・課金 | 配当の森の Cognito User Pool に App Client を追加（サイレントアカウント）。課金検証APIは配当の森と共用。**新しいAWSリソースは作らない** |
| 広告 | フリーのみ（AdMob） |
| アプリ間連携 | 統合ダッシュボード向けに、月次の要約を端末内に書き出す（iOS App Groups / Android ContentProvider）。形はファミリー共通の取り決め `specs/family/app-link.md`（Specs #107）に従う |
